# 🍲 Vô Pereirinha - Marmitaria

> **Primeiro projeto web!** 🎉  
> Este é o primeiro site que desenvolvi, criado para a **Marmitaria Vô Pereirinha**. O objetivo principal do projeto é apresentar o estabelecimento e facilitar os pedidos dos clientes através de canais diretos de comunicação.

---

## 📌 Sobre o Projeto

O site da marmitaria **Vô Pereirinha** foi desenvolvido para ser uma página institucional simples, objetiva e acolhedora. Ele permite que as pessoas conheçam o espaço/serviço e façam seus pedidos rapidamente.

### ✨ Funcionalidades Principais
- 🏠 **Apresentação do local:** Seção informativa sobre a marmitaria.
- 💬 **Pedido via WhatsApp:** Botão direto para iniciar uma conversa e fazer o pedido.
- 📸 **Rede Social:** Botão de acesso direto ao perfil oficial no Instagram.
- 📱 **Layout Amigável:** Estrutura simples e focada na usabilidade do cliente.
